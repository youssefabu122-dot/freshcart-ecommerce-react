# FreshCart E-Commerce

FreshCart is a front-end e-commerce application built with React and Next, featuring product browsing, user authentication, shopping cart management, wishlist functionality, and order processing.

## Features

### Authentication
- Login
- Register
- Forgot Password
- Change Password

### Home
- Homepage with product listings and categories

### Products & Categories
- Products Listing
- Product Details
- Brands Listing
- Brand Details
- Categories Listing
- Category Details

### Shopping Cart
- Display Cart
- Add Products
- Remove Products
- Update Product Quantities

### Wishlist
- Display Wishlist
- Add Products
- Remove Products

### Checkout & Orders
- Online Payment
- Cash Payment
- Orders Page
